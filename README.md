# Calculator

Простой калькулятор на GridLayout: два поля ввода, знак операции между ними и поле результата.

- Числовая клавиатура открывается при нажатии на поле ввода
- Кнопки `+`, `-`, `*`, `/` меняют знак между операндами и считают результат
- Деление на ноль показывает «Ошибка»
- Кнопка `C` очищает оба поля, результат и возвращает знак `+`
- Экран собран на `GridLayout` и помещается в портретной и альбомной ориентации
- На экране есть ФИО и группа

## Сборка

Нужны Android Studio и JDK 17.

```
gradlew.bat assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`
